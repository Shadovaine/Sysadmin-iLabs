## Overview

This is an interactive lab that guides a user through managing linux services.

## Lab Features:

- Check service status
- Start a service
- Stop a service
- Viewing a service logs
- Enabling a service
- Disabling a service
- Checking if a service exists


**To Run Lab**

```bash
./service-management/lab.sh
```
