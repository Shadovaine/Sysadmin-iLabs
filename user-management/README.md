## Overview
This lab walks a user through user creation workflow inside a safe containized environment. The script prompts the user to create a new user, by entering a new username, then moves onto prompting for the password. The commands are ran in the background. The next section will prompt the user to verify the account is successfully made. It also provides the option to view the home directory set for the new account. Lastly, the ability to delete the new user is given inside the script. 

## Features
- Creates a new user
- Sets a password
- Verifies account details
- View the user's home directory
- Ability to Delete or Reset a lab user

### This lab has the option to be tested within Podman container environment described in the Sysadmin-iLabs README.md.

**To Run Lab**

```bash
./user-management/lab.sh
```
